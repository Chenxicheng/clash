# AGENTS.md

## Project Scope

This repository stores Clash configuration files.

## Structure

- `Clash.yaml`: main Clash configuration.
- `AGENTS.md`: project working rules.

## Rules

- Keep configuration changes minimal and explicit.
- Validate YAML syntax after editing `*.yaml` files.
- Do not commit secrets, subscription URLs, tokens, or passwords.
- Before deleting or replacing config files, inspect the target first.
